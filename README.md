# Метод Гаусса у PARCS

Лабораторна №1 з хмарних обчислень. Програма розв’язує систему лінійних рівнянь послідовно та за допомогою 1, 2 і 4 воркерів у PARCS. Master обирає опорний рядок, воркери одночасно обробляють свої рядки матриці. Наприкінці порівнюються час і правильність результату.

Основний алгоритм лежить у `gauss_lab/`, модуль PARCS — у `solution.py`, налаштування запусків — у `configs/`.

## Локальний запуск

Потрібен Python 3.11–3.13. У Windows відкрий `quick_demo.cmd` у цій папці: він встановить залежності та запустить короткий приклад. Результати будуть у `results/quick-demo/`.

## Google Cloud

Завантаж архів лабораторної в Cloud Shell, розпакуй і перейди до папки з кодом:

```bash
cd ~/Gauss_PARCS_Cloud/code
python3 -B cloud.py deploy --project gauss-parcs-lab --zone europe-west1-b --apply
python3 -B cloud.py run --config smoke
python3 -B cloud.py run --config cloud
```

Для іншого хмарного проєкту заміни його назву в першій команді запуску. Основний експеримент перевіряє системи на 500, 1000, 2000 і 3000 невідомих, по п’ять повторів. Результати зберігаються в `results/downloaded/gcp/`. Після їх завантаження прибери створені ресурси командою `python3 -B cloud.py destroy --apply`.

Три PDF зі звітом, захистом і поясненням лежать поруч із папкою `code`.

В основі `parcs_py/` — [PARCS-Python](https://github.com/Hummer12007/parcs-python), адаптований для Python 3. Початкова версія: `00c53991f5d8385b8074e2430f3e3d716e314c52`.
